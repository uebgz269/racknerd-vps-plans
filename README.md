## 建站要多少配置：1GB 够不够，2GB 是不是浪费

跑 WordPress（MySQL + PHP 那一套），1GB 内存是及格线，2GB 才是从容。512MB 也能把系统装进去，但你加个缓存插件、装个安全插件，后台就开始转圈，更新一篇文章要等半天。

硬盘从 20GB SSD 起。WordPress 本体不大，吃掉空间的是主题、插件、图片和备份文件，再加上系统日志。RackNerd 三款分别给 20GB、35GB、60GB，按站点数量往上选就行。

具体到这三款怎么分：

1GB 款适合单站点、内容以文字为主、装了缓存插件、月访问量几千的博客。它跑得动，但别在上面装十几个插件，也别指望后台操作有多流畅。

2GB 款多出来的不只是 1GB 内存，还有一倍的 CPU 核数和 15GB 硬盘。WordPress 后台、插件更新、图片压缩这些吃资源的操作会明显顺一些。做企业展示站、写长文博客、偶尔跑个小工具，这一档是性价比拐点。

4GB 款面向多个站点、WooCommerce 商城，或者要在这台机器上同时跑点别的东西。单个博客买它，多出来的资源基本闲置。

有一点值得说清楚：1 vCPU 不等于独享一颗物理核心，它通常只是分配给你的虚拟核心或计算时间。同样标着“1 核 1G”的两台机器，差价可能来自 CPU 型号的代际和主频、硬盘是 SATA SSD 还是 NVMe、机房和线路、超售程度、有没有备份和售后。看配置表只能判断能不能跑，判断不了跑得多顺。

关于这台机器能撑多大的站，一个实测过 RackNerd 的建站博主给过一条边界：配合 WP Panel 这类面板拦截恶意访问之后，放一两个没什么流量的企业官网问题不大；网站已经有稳定流量了，就该换性能和稳定性更好的机器。这条线画得挺实在，把它当成 RackNerd 的能力上限来理解比较合适。

## RackNerd 的线路属于哪一档，国内访问要不要指望它

美国机房对国内访问，线路大致分四档，价格和体验差得远：

**国际线路（BGP/Global）** 走普通公网，最便宜，国内访问延迟高，晚高峰可能丢包。适合目标用户在海外，或者纯练手。

**9929 + CMIN2 优化** 是联通 AS9929 加移动 CMIN2，电信、联通、移动三网都有优化，价格比国际线路高一档，是大多数中文站长觉得划算的位置。

**CN2 GIA** 是电信精品网，回程走 GIA，晚高峰也稳，价格最贵。洛杉矶的 CN2 GIA 机器到国内实测在 150–180ms 这个量级。

**双 ISP** 卖的是 IP 归属显示为美国本土 ISP，用在流媒体解锁、TikTok 这类场景，和建站速度关系不大。

RackNerd 的位置需要说清楚。它的洛杉矶机房在页面上标了 Asia optimized network，但套餐名里不写线路类型，也没有把 CN2 GIA 或 9929+CMIN2 做成明码标价的产品线。同价位里主打中国大陆优化的商家，会把线路类型直接写进套餐名，因为那是他们要卖的东西。所以实际买到的机器，大概率落在普通国际线路这一档。

这意味着什么：给海外用户看，没问题；国内用户打开会比 CN2 GIA 的机器慢，晚高峰的抖动也更明显。你自己的后台操作同样受影响，装个插件、传张图都要等。

判断规则很简单，按访客位置走：

- 访客主要在海外 → 选目标客户附近的机房，线路不用额外花钱
- 访客主要在国内、对打开速度有要求 → 需要 9929+CMIN2 或 CN2 GIA，RackNerd 这一档解决不了
- 国内海外都有 → 洛杉矶机房加一层 CDN，比单纯堆线路预算更实际

另外，不要只看“CN2”三个字。同样标 CN2，GIA 和 GT 的晚高峰表现差很多，机房和实际路由也要看。

## 下单前必须知道的三件事：非托管、不退款、自己备份

这三条都写在 RackNerd 的条款和产品页里，但推荐文里很少提。

**第一，VPS 默认是非托管的。** 条款写明 VPS 服务“默认不提供管理”，商家的责任限于服务器硬件、电力、网络连通性和服务可用性，24 小时提供的是这部分的尽力支持。软件、操作系统、应用程序、代码、防火墙配置、服务器加固、恶意软件清理、网站开发、脚本排错、第三方应用支持，都不在支持范围内。需要管理服务可以额外付费申请。

直白点讲：买这台机器，环境要自己装，出问题要自己查。你是新手、连 SSH 都没用过，先想清楚这一点。

**第二，默认不提供退款。** 条款里没有无理由退款窗口，需要退款保障的话，先用月付周期试一个月，确认没问题再转年付，比一上来就押一整年稳妥。

## 机器到手后的四步：解析、面板、缓存、备份

这几步和 RackNerd 无关，任何一台空机器都要做。

**域名解析。** 买机器之前先把域名准备好，把 A 记录指向分配到的 IP。这一步不做，网站装好了也打不开。

**装面板。** 不熟悉命令行的用 1Panel、宝塔、aaPanel 这类可视化面板，LNMP 环境和 WordPress 可以一路点下来。RackNerd 支持 CentOS、AlmaLinux、Debian、Ubuntu 等常见系统，重装系统在控制面板里就能完成。

**开缓存。** WordPress 装个缓存插件，服务端再加一层页面缓存，同一台机器能扛的访问量能差出好几倍。低价机器尤其需要这一步。

**做备份，做安全加固。** 面板定时备份导到对象存储，或者用插件定期导出数据库。安全这边，改掉默认 SSH 端口、禁用 root 密码登录、装 fail2ban、定期更新系统，都是基本操作。便宜 VPS、误操作、插件冲突、商家故障，任何一种都能让数据归零。

另外，如果你需要 IPv6，洛杉矶和法国机房可以免费申请，下单后开工单最多能要到 100 个地址。这个对建站本身影响不大，但需要的时候省事。
